# 🍻 D-Order V1

> 대학 축제 주점 통합 운영 플랫폼 (Version 1)

동국대학교 축제 주점 운영을 위해 개발한 주문·관리 서비스입니다.
수기로 진행되던 주문과 운영 과정을 디지털화하여 주문 처리와 운영 효율을 개선하는 것을 목표로 개발했습니다.

## ✨ Main Features

- QR 기반 주문 시스템
- 메뉴 조회 및 주문
- 주문 내역 관리
- 테이블 내역 관리
- 관리자 페이지
- 부스 운영 기능
- REST API 기반 프론트엔드 연동
